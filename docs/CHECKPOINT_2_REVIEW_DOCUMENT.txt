1. EXECUTIVE SUMMARY & PROBLEM UNDERSTANDING (CHECKPOINT 1 RECAP)
--------------------------------------------------------------------------------
* The Problem:
  Students do not fail because they lack capability; they struggle because unseen
  prerequisite gaps from earlier grades compound silently over time. When a student
  struggles with an advanced topic like Quadratic Equations, traditional platforms
  give them more quadratic problems, ignoring that their foundation in negative sign
  rules or factoring polynomials is broken. Additionally, rigid study timetables
  cause burnout, and English-only STEM content alienates vernacular-medium students.

* The Solution — Roots & Rhythm:
  A production-grade, mobile-first educational web platform built on two core pillars:
  1. ROOTS (Prerequisite Gap Finder & Root-Cause Tracer):
     An educational X-Ray dependency graph (DAG) that inspects learning stumbling
     blocks backwards to pinpoint exact foundational root causes.
  2. RHYTHM (Free-Hour Study Planner & Rebalancer):
     A calm scheduler where students declare their actual daily free hours. Micro-study
     sessions target their root causes strictly inside declared free hours, with
     auto-rebalancing when sessions are skipped.

--------------------------------------------------------------------------------
2. COMPLETE END-TO-END SYSTEM WORKFLOW
--------------------------------------------------------------------------------
Step 1: Student Onboarding & 5-Language Preference Setup
  - The student selects their preferred language (English, Hindi, Kannada, Tamil, Telugu)
    and learning speed mode (Beginner 15m, Intermediate 25m, Advanced 45m).

Step 2: Diagnostic Assessment (Gap Finder)
  - Student takes topic-based diagnostic assessments. If performance falls below 70%,
    the topic is flagged as an active learning gap with severity classification.

Step 3: Root-Cause X-Ray (SVG Topological Dependency Graph)
  - The engine executes a Directed Acyclic Graph (DAG) backward traversal.
  - Pinpoints the deepest unmastered foundational prerequisite (e.g. Factoring Polynomials
    behind Quadratic Equations) and renders an interactive SVG node map with color-coded
    radar auras (Rose = Root Cause, Amber = Shaky, Emerald = Mastered, Indigo = Target).

Step 4: Availability Declaration (Free-Hour Input)
  - Student inputs their daily/weekly free hours (e.g. 17:30–18:30 After-School Focus).

Step 5: Constraint-Based Study Scheduler & Auto-Rebalancer
  - Schedules bite-sized micro-sessions targeting foundational gaps strictly within
    declared free hours. If a session is missed, the auto-rebalancer redistributes it
    without cognitive overload or double-booking.

Step 6: AI Learning Assistance & Adaptive Practice
  - AI Assistant provides step-by-step doubt clearing using intuitive analogies in
    the student's chosen language.
  - Practice drills provide calibrated questions with progressive hint ladders and
    curriculum verification badges.

Step 7: Mastery Dashboard & Multi-Role Oversight
  - Real-time mastery score updates (+15 points on completion). Once mastery reaches
    80%, the gap is marked as "Resolved".
  - Teachers view class-wide heatmaps; parents receive jargon-free weekly summaries.

4. COMPLETE TECHNOLOGY STACK ARCHITECTURE
--------------------------------------------------------------------------------
* Backend Application:
  - Python 3.10+ / 3.14 with Flask 3.1 / ASGI, clean RESTful JSON routes.
  - Architecture: Layered MVC pattern with dedicated service engines (gap_finder.py,
    planner.py, ai_service.py, validator.py).

* Database & Persistence:
  - SQLite 3 relational database with foreign key cascades and relational indexes.
  - Topological curriculum dependency DAG schema and automated data seeding.

* AI & Pedagogical Layer:
  - Dual-Engine Architecture:
    a) Primary: Google Gemini API (gemini-2.0-flash / 1.5-flash) for generative tutoring.
    b) Deterministic Fallback: High-fidelity offline pedagogical knowledge engine.
  - Safe Guardrails: OWASP prompt-injection filters and answer verification ratings.

* Frontend & Tactile UX:
  - Vanilla Modern JavaScript (ES6+), HTML5, SVG dynamic node canvas, Tailwind CSS.
  - Chart.js for mastery analytics, teacher heatmaps, and parent summaries.
  - Native Web Audio API Synthesizer (pink/brown noise & alpha binaural beats).
  - Physics confetti celebration engine (canvas 60fps).

* Security & Multi-Role Access Control (RBAC):
  - Server-side role-based decorators protecting Student, Teacher, Parent, and Admin views.
  - Password hashing with Bcrypt, CSRF protection, and strict session isolation.

* Quality Assurance:
  - Comprehensive automated test suite covering all core user flows and RBAC enforcement.
